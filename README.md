# SwiftShip-Tracking
Salesforce-based parcel management and tracking system using flows,AgentForce AI,Promt Builder, and Experience cloud
## Project Overview
SwiftShip Tracking is a Salesforce-based parcel management and tracking system designed to manage parcel information and provide easy parcel tracking.

## Features
- Parcel booking and record management
- Parcel status tracking
- Sender and receiver information
- Delivery agent status updates
- Automated notifications
- Salesforce Flow automation
- AgentForce AI for conversational parcel tracking
- Prompt Builder for AI-powered responses
- Experience Cloud for customer access
- Reports and dashboards for tracking and insights
- Security using Salesforce permissions and access controls

## Technologies Used
- Salesforce
- Salesforce Flows
- AgentForce AI
- Prompt Builder
- Experience Cloud
- Apex
- Reports and Dashboards

## Objective
The main objective of SwiftShip Tracking is to provide centralized parcel management and tracking while reducing manual work through Salesforce automation and AI.

## Future Scope
- Real-time parcel tracking
- More AgentForce capabilities
- Advanced delivery analytics
- More external logistics integrations
- Improved AI conversations
- Enterprise deployment using sandbox and CI/CD

## Conclusion
SwiftShip Tracking demonstrates how Salesforce automation and AI can be used to create a user-friendly parcel management and tracking solution.
